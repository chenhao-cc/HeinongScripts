## Project Overview

The **HeiNong** genome project aims to provide high‑quality whole‑genome assembly, annotation, and downstream analysis pipelines for **HeiNong**related species. This repository hosts custom scripts, analytical workflows, and auxiliary tools for processing genomic data, covering the entire spectrum from raw sequencing quality control to functional gene annotation.

The final genome assemblies and detailed annotation files (GFF, CDS, protein sequences, etc.) are distributed via Baidu Netdisk for direct download and use.

The assembled genome sequences and annotation files (GFF3, protein FASTA, CDS FASTA, etc.) are available at the following Baidu Netdisk link:

**Link**: https://pan.baidu.com/s/1pUOCBIrU_0sJPQC6U-0SOg  
**Extraction code**: `8hfu`
